# Академ-разница

Канбан для двоих студентов (Д и M), которые закрывают академическую разницу.

## Колонки

- **Д** / **M** — личные экзамены и зачёты
- **Общие** — то, что логично сдавать вместе
- **Done** — закрыто

Карточка = один экзамен или зачёт. На карточке: предмет, код, преподаватель, тип, владельцы. Подсветка совпадений:

- **идеал** — оба студента, один предмет (+ препод)
- **общий препод** — разные предметы, один преподаватель

Данные хранятся в `localStorage` браузера.
